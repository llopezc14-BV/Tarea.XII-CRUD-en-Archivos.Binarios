Este proyecto es realizado por c++ consiste en un sistema de gestión de productos y ventas desarrollado 
El programa nos permite registrar productos, lista de productos activos, buscar productos por código o nombre, 
modificar precios, actualizar stock y desactivar productos. Además, nos permite un proceso de venta básico donde se 
valida el stock disponible, se calcula el subtotal, el IVA y el total de la compra.

El sistema utiliza estructuras (struct), funciones y archivos binarios (productos.dat) para almacenar la información 
de forma persistente, permitiendo que los datos permanezcan guardados aunque el programa se cierre y se vuelva a abrir. 
También incluimos validaciones básicas para evitar errores al momento del ingreso de datos y en el proceso de ventas.
